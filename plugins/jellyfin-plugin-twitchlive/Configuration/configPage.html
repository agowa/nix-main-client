Twitch Live TV

One channel per line. These are Twitch logins, not display names - the part of the channel URL that comes after twitch.tv/. Saving applies by itself: it queues the same rebuild the server runs when a tuner device is added, so channels also move between the live and offline groups without anyone starting a task.

Logins are matched case-insensitively. A login that does not exist stays in the offline group, and the guide says so.

Account (optional)

Everything above works without a Twitch account. An OAuth token adds three things: the ad-free rendition your channel subscription or Twitch Turbo entitles you to, the broadcaster's own schedule through the documented API rather than the public feed, and the channels this account follows. Get one at twitchtokengenerator.com (tick user:read:follows if you want the follow list) or from your own app at dev.twitch.tv/console.

Stored in this plugin's XML file under the data directory and sent only to api.twitch.tv, id.twitch.tv, gql.twitch.tv and usher.ttvnw.net. Revoke it at twitch.tv/settings/connections.
Twitch decides whether to mark ad breaks when it hands out the playlist, and it can only do that if it sees the paying account on the request. Off means playback stays anonymous and ad-supported. No effect while the token field is empty.
Followed logins are added below the ones typed above and re-read every so often, so following someone new shows up as a channel on its own. Needs the scope user:read:follows.
Newest follow first. Every channel costs guide work, so a few hundred is already a lot.

Guide

Turns the guide into actual appointments for channels that publish one. The public feed is used, so this needs no login; a channel without a schedule keeps its generated entry.
Twitch publishes about a week either way, so more than 7 mostly costs requests.
How far a live stream with no published end is extended. Where the channel's own schedule says what comes next, that ends the entry earlier.
On: every channel keeps its place and the guide says "offline". Off: only live channels appear at all, so the list grows and shrinks with each refresh.
The picture arrives with the live/offline answer that is fetched anyway, so this costs no extra requests. Stream thumbnails and category art are attached to the guide entries.

Playback

Lets the playlist include the broadcaster's original stream, which is often better than the standard transcode. Maps to usher's allow_source.
One request answers every configured channel.
Only the first request of a stream needs a token, so this does not limit how long a stream runs.
The public id of the twitch.tv player. Replace it with your own from dev.twitch.tv only if you want to - a token must have been issued for the client id it is sent with.
